# To-Do CLI Application

A simple command-line To-Do Manager application built with Node.js as part of training.

## Overview

This project is a beginner-friendly CLI application designed to help manage daily tasks directly from the terminal. It uses standard Node.js modules and stores data locally in a JSON file.

## Features

- Add new tasks
- View task list
- Mark tasks as complete
- Update task details
- Delete tasks
- Persistent local JSON storage

## Technologies Used

- Node.js
- JavaScript (CommonJS)
- npm
- readline module
- fs & path modules

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd todo-cli-app
   ```
3. Ensure Node.js is installed on your system.

## Running the Project

Run the application using npm:

```bash
npm start
```

Or directly with node:

```bash
node src/app.js
```
